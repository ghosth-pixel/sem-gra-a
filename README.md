# Tigelinha — Painel de Vendas

Primeira versão do painel.

## Como testar

Abra `index.html` no navegador.

Os dados desta versão ficam no `localStorage` do navegador. Isso é apenas para protótipo/teste; não use essa versão para armazenar credenciais reais de clientes.

## Próxima etapa

Migrar os dados para um backend/banco de dados com autenticação, regras de acesso e armazenamento seguro de credenciais. O GitHub deve conter o código do painel, não segredos ou senhas.
